## 財務フォーム (Financial Form Generator)

Webブラウザ上で動作する、1ファイル完結型のシンプルな帳票作成ツールです。<br>
見積書、発注書、請求書などのビジネス書類をブラウザ上で素早く作成し、PDFやJPGとして出力・ダウンロードすることができます。<br><br><br>

<h2> 特徴 </h2>

サーバー不要: 1つのHTMLファイルだけで動作するため、ダウンロードしてブラウザで開くだけですぐに使えます。<br><br>
多様なフォーマット: 以下の書類フォーマットに対応しています。<br><br>
◇見積書<br>
◇発注書<br>
◇購入許諾書 (稟議)<br>
◇支出報告書 (経費精算)<br>
◇請求書<br><br>
PDF / JPG 出力: 作成した書類は、A4サイズのPDFや画像(JPG)として綺麗に出力できます。<br><br>
自動計算機能: 単価と数量を入力すると、金額や消費税（10%）が自動で計算されます。<br><br><br>

<h2> 使い方 </h2>

本リポジトリからgithub pagesに飛び、お使いのWebブラウザ（Chrome, Edge, Safariなど）で開きます。<br>
画面上部から作成したい書類の種類を選択します。<br>
宛先、作成者、件名、明細などの必要事項を入力します。<br>
画面右上の「PDF出力」または「JPG出力」ボタンをクリックして、書類を保存します。<br><br><br>

<h2> 使用技術 </h2>

〇 HTML5 / CSS3 / Vanilla JavaScript<br><br>
〇 html2canvas - 画面キャプチャ用ライブラリ<br><br>
〇 html2pdf.js - PDF生成用ライブラリ<br><br><br>
